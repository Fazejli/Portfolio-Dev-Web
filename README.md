# Portfolio-Dev-Web

## 📖 Description

Bienvenue sur mon portfolio de développement web ! Ce projet présente mes compétences, mes projets et mon expérience en développement web.

## 🚀 Fonctionnalités

- Portfolio interactif et responsive
- Présentation de mes projets
- Section à propos
- Formulaire de contact
- Design moderne et épuré

## 🛠️ Technologies Utilisées

- HTML5
- CSS3
- JavaScript
- Autres technologies à venir...

## 📦 Installation

```bash
# Cloner le repository
git clone https://github.com/Fazejli/Portfolio-Dev-Web.git

# Naviguer dans le dossier du projet
cd Portfolio-Dev-Web

# Ouvrir le fichier index.html dans votre navigateur
```

## 💻 Utilisation

Ouvrez simplement le fichier `index.html` dans votre navigateur web préféré pour visualiser le portfolio.
